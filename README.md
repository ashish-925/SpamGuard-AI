# 🛡️ SpamGuard AI

AI-powered spam message detection using Machine Learning.

## Features
- Spam / Not Spam classification
- TF-IDF text vectorization
- Logistic Regression model
- Confidence score
- Django web interface
- Interactive message checking

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Django
- HTML
- CSS
- JavaScript

## Machine Learning Pipeline

Message → TF-IDF → Logistic Regression → Prediction

## How to Run

pip install -r requirements.txt
cd spam_project
py manage.py runserver
